# 测试与验收清单

## 通用
- [ ] 每阶段：编译通过、记录固件尺寸与 app0 占比、串口日志无 Guru/assert。
- [ ] 烧录前整片 flash 备份存在且可读；回滚命令已给出并验证可执行。
- [ ] 三态（SAVED/SENT/ACKED）在所有工具返回中正确体现。

## UI（阶段 C）
- [ ] 横屏 320×240 目视编号卡验证（`offset/invert/rgb_order/swap` 未走样）。
- [ ] 六页逐页显示，中文无豆腐块，长文本 `LV_LABEL_LONG_DOT` 不越界。
- [ ] 触摸点击、左右滑动有效；连续切页 100 次无残影。
- [ ] Flash 余量 ≥ 100 KB。

## 通信（阶段 D/F）
- [ ] 任务 / 备忘 / 提醒 / 摘要四类消息全链路。
- [ ] USB 拔出 → 入队 → 插回 → 补发。
- [ ] 设备重启 → 全量恢复；重复 `id` 不重复；超时重试点触发。
- [ ] 串口不阻塞 LVGL（帧率/刷新日志）。
- [ ] Bridge 连续运行 24 h 无崩溃；kill -9 后重启数据不丢；日志无私人内容。

## 隐私（阶段 G，7 项）
- [ ] 开机默认 Guest；锁屏→Guest；解锁→授权后 Owner。
- [ ] USB 断开保持 Guest；Bridge 重启保持 Guest；Guest 下无法进入私人页。
- [ ] 切换 100 次无私人文本残留（抓 LVGL 对象树文本核对）。

## 稳定性（阶段 H，72 h）
- [ ] heap 最低值、LVGL 内存、帧率/刷新异常、串口异常、USB 重连、UI 卡死、消息丢失、SQLite 完整性。
- [ ] 开机自启、端口自动发现、断线重连、日志轮转、错误上报、优雅退出。

## MCP（阶段 E）
- [ ] 配置写入后工具发现列表包含全部 18 个工具名。
- [ ] 逐个调用只读工具；写工具拿到真实设备 ACK；未确认接收时返回未确认状态。

## 技能自检
- [ ] 新开会话用触发词调用本技能成功；回读 `SKILL.md` 确认加载；能回答只有本项目才知道的参数（如 `LCD_PIXEL_SWAP`）。
