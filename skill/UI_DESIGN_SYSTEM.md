# UI 设计规范（来源：B 交付包 `docs/01_视觉设计规范.md`、`03_页面与状态说明.md`）

## 画布
逻辑画布 **320×240 横屏**，原点左上。目标设备经典 ESP32 / 4MB Flash / 无 PSRAM / LVGL 8.3.11。视觉关键词：温暖、克制、轻量、可信赖；避免冷蓝科技仪表盘与密集表格。

## 六页
1. 启动页：品牌、产品定位、标语；启动后默认 Guest。
2. 首页：问候、日期、任务/提醒计数、WorkBuddy 摘要、下一项任务。
3. 任务中心：最多 5 条精简任务，长内容进详情页。
4. AI 备忘：摘要与备忘卡片，仅显示摘要片段。
5. 智能提醒：时间、事项、简短说明、确认入口。
6. 访客模式：日期时间、离开提示、公开每日一言；不显示任何私人内容。

> **品牌字与开机画面（2026-11-08 晚，现行）**：中文「晴屿」墨色，拉丁 `SUNISLE` **朱砂**。开机画面为**横排品牌锁**：32×32 canvas logo（朱砂日＋墨色三角岛＋青瓷海平线，贴合「晴屿」=晴+屿字义）`(62,66)`＋「晴屿」28 px 楷 `(106,67)`＋`SUNISLE` 14 px 字距 5 `(172,82)`，副标「渑池高中AI桌面助理」`TOP_MID y=158`；启动**淡入+淡出共 4 s**（1200/1600/1200）。顶栏 `SUNISLE` 66,11 字距 3 朱砂；demo 态右上角状态字由「DEMO」改「渑池高中」。
> **现行实现（UI 2.3，2026-11-08）已压缩为四屏**：BOOT / HOME / MEMOS / GUEST。任务中心与提醒页合并进 MEMOS（上半智能提醒、下半 AI 备忘），本节 3–5 为历史设计。GUEST 已删除全部说明性标签（「现在时间」「每日一言」「访客模式」「欢迎来访」），只保留：顶栏品牌 → 56 px 时间（`TOP_MID y=68`）→ 16 px 日期（y=116）→ 朱砂细线（136,144,48,2）→ 16 px 提示（y=156）→ 底部描边引文卡（16,204,288,30）。判据：一句话若只是复述画面已表达的信息，就不写。

Owner 页面枚举：`QY_PAGE_HOME / TASKS / MEMOS / REMINDERS`；隐私枚举 `QY_PRIVACY_GUEST / OWNER`。状态优先级：Guest > Reminder overlay > Current owner page。任何未知状态默认 Guest。

## 排版与资源约束
- 只用精简中文字体，不引入完整 CJK 字库。标题 12–16 px、正文 10–12 px、辅助 8–10 px。
- 单条摘要 ≤ 2 行，Bridge 侧先截断；长文本用 `LV_LABEL_LONG_DOT`。
- 不用大尺寸双缓冲；不在 LVGL 回调内执行串口阻塞操作。
- 常驻页面避免大面积高亮与频繁动画；闲置降背光由硬件层负责。

## 交互
- 左右滑动切换四个 Owner 页面；点击任务进入详情/完成；点击提醒确认/稍后（均由集成层补齐）。
- Guest 锁定页面导航，普通触摸不得进入 Owner。
- 上电、复位、Bridge 无法确认会话、USB 重连：均保持 Guest，直到授权层明确放行。

## 集成注意（阶段 C）
- 组件 `style_page()` 硬编码 `lv_obj_set_size(p,320,240)`，卡片 `x=16,w=288` 右边界 304 —— 只有 G1 横屏生效后才成立。
- 组件用 `lv_scr_act()` 建对象，与 A 的 `ui_manager` 冲突 → B 独立工程、独立 screen。
- 组件全部 label 用 Montserrat 占位 → 必须换成子集中文字体，且文案定稿后重新生成字库。
- `build_tasks()` 的 `ys[]` 越界必须修；`show_boot()` 启动页必须补；两个未绑定回调与滑动手势必须接线。

## 项目视觉约定（2026-11-08 用户反馈，长期有效）
- 不要「全部横排 + 单一字号」：需有横竖混排、大小字对比、左/右/居中对齐混用、轻微错位节奏。
- 克制前提仍成立：清新不俗、文雅不乱、不要堆装饰元素。设计感靠**排版与字体对比**实现，不靠新增图案。
- 已落地的手段：竖排中文栏目标签（逐字 `\n`，UTF-8 安全）、Kai 标题 vs 黑体正文、28 px Latin 大字时钟、卡片交替缩进 8 px、页码 18 px。
- 中文标点（`，。、！？；：（）`）必须与文字同字库，不能指望 Montserrat fallback。
- 任何长文本 label 必须 `LV_LABEL_LONG_WRAP` + 固定宽高；字符串缓冲区按 **3 B/汉字** 估算，不要用 48 B 装 20 字以上的句子。

## UI 2.0 设计规范（2026-11-08 待确认，取代此前的奶油米黄体系）
- 色彩 Token：`BG #F4F6FA` / `SURFACE #FFFFFF` / `INK #171D2B` / `MUTED #697586` / `BRAND #5267F6` / `TECH #38B8C8` / `SUCCESS #A7D66D` / `ALERT #F08B72` / `LINE #E6EAF0`；GUEST 反相为 `#171D2B` 背景。
- 字体层级：`NUM_XL 34px` 数字 / `TITLE 18px` / `HEADING 16px Kai` / `BODY 14px` / `CAPTION 10–12px`；同屏至少 4 级字号，不全部加粗，不全部横排。
- 320×240 网格：左右安全边距 16 px、内容宽 288、顶栏 30 px、分页点右下角 (292/302, 230)。
- 页面：BOOT（1.5 s）、HOME（时间主视觉 + 任务进度卡 + 无卡摘要 + 下一项）、MEMOS（上提醒下备忘）、GUEST（覆盖式隐私状态，不显示页码）。
- 组件：圆角 8 px 卡片、无阴影无渐变、单页 ≤2 卡、线性自绘图标、按钮圆角 6、次按钮 `MUTED` 描边。
- 逐元素坐标与交互流程以 `UI2_DESIGN/晴屿_UI2.0_视觉设计规范.md` 为准。此前的竖排标签/楷体对比仍可沿用，但色系与页面结构已作废。
