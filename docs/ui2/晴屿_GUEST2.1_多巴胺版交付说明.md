## 2. 触摸：第四、五轮独立探测

用户确认按压有效且一体化屏触摸可用，因此不再沿用「无硬件」结论，改为排查**探测方法本身**。

### 2.1 新增三条独立路径

| 命令 | 方法 | 排除的旧假设 |
| --- | --- | --- |
| `TOUCHSPI[=<cs>,<ms>]` | Arduino `SPIClass(HSPI)` 全双工 `transfer()`，同一组 14/12/13 引脚 | 旧三轮全用 `lgfx::spi::readBytes()`（面板 ID 助手，依赖 LGFX bus init 是否启用 `SPI_USR_MISO`） |
| `TOUCHMISO[=<cs>]` | `spiAttachMISO()` 经 GPIO matrix 换 MISO 输入脚，扫 12/22/25/26/27/32/33/34/35/36/39/4/16/17 | 旧三轮固定 MISO=GPIO12 |
| `TOUCHMATRIX` | 14 MISO × 9 CS = 117 组合，每格 4 次读 | 旧三轮固定 CS∈{33,32,…} 且未做组合 |
| `TOUCHIRQ[=<ms>]` | 只读 GPIO 电平监控 + 同窗口 SPI 采样，一次按压拿两类证据 | 旧三轮只看 SPI，未找 PENIRQ |

探测**不注册 LVGL indev、不碰 LCD_CS(15)/DC(2)/SD_CS(5)/BL(21)**；曾误把 SD 的 VSPI 引脚 19/23 纳入 MISO 扫描导致 `sdCommand(): Card Failed`，已剔除并在最终固件验证 `SD ready=YES`、重启后 `MOUNT OK`。

### 2.2 结果

- `TOUCHSPI` CS 扫描：33/32/25/26/27/22/21 → `00 00 00`；16/17/4 → `FF FF FF`。cs=33 连续 3 s 在 `00 00 00 ↔ FF FF FF` 间振荡，出现过一次 `D1 00 00`（MOSI 回环特征），**无 12 位 ADC 值**。
- `TOUCHMISO`：15 个 MISO 脚里仅 `miso=16` 出现过一次 `00 00 FF`（x=31），其余全 0 / 全 FF。
- 15 s 按压窗口（用户已按压）：`spi33 frames=150 changes=1`，即整段按压期间 SPI 读数几乎恒定；GPIO16 翻转 107 次、GPIO39 翻转 267 次，但二者互补且 ~18 次/秒，**与按压节奏不符，判为浮空噪声/串扰，非 PENIRQ**。
- `TOUCHMATRIX`：117 组合、67 个非平凡，全部是 `FF FF FF`（上拉浮空），**没有任何组合返回 XPT2046 应有的中间 ADC 值**。
- I²C（前三轮）：7 组 SDA/SCL 全地址 `devices=0`。

### 2.3 结论与下一步

软件层已完备且可逆（`TOUCH=on|off`、CS/映射可调、tap→页面动作、GUEST 忽略 tap），显示全程稳定无白屏。但按 ESP32 常见 ST7789 一体化板的引脚定义，**MISO、CS 的全部常规组合都读不到触摸控制器**，所以现在给不出坐标，不能声称触摸可用。

硬件确定可用的前提下，只差**这块板的具体引脚定义**。请提供任一项：

1. 板子背面丝印 / 型号（例如 `ESP32-2432S028R` / CYD / 2.8″ / 2.4″），或整机商品页；
2. 触摸控制器型号与 CS、DOUT(MISO)、PENIRQ 实际接到哪个 GPIO；
3. 一张板子 / 排线照片。

拿到定义后 `TOUCHCS=<pin>` + 必要时改 `LCD_MISO` 常量 + `TOUCH=on` 即可直接用现有层，不必再改架构。若触摸实际挂 VSPI 或 I²C 的其他引脚，按型号补一段初始化即可。硬件确认前交互继续走 `NEXT` / `ACT=ack|later|detail|task` / `PAGE=home|memos|guest` / `PRIVACY=owner|guest`。
